# 园区网到底长什么样：流量构成、集中度与窗口内稳定性（中文说明）

对一次企业园区网核心采集位置的抓包做统计分析：这份流量**是什么**（构成、集中度、谁在与谁通信）、
**随时间怎样变化**，以及哪些偏离值得追下去。完整英文说明见 [README.md](README.md)。

本仓库包含**分析代码、绘图代码与全部图表**（PNG + SVG）。书面报告单独提交，不放入本仓库。

## 分析对象

| 项目 | 数值 |
|---|---|
| 抓包文件 | 4 个（`cap_20260920_111416/112321/112821/113321.pcap`） |
| 规模 | 36.2 GB、6,870 万包（68,696,735） |
| 有效窗口 | 两个连续观测段：192 秒 + 842 秒 = 17.2 分钟（文件 2–4 首尾相接） |
| 主机 | 49,560 台（内网 5,223 + 外部对端 44,335 + 回环 2） |
| 会话（≥2 包） | 693,484 场 |
| 字节口径 | 单向；回环与非 IP 流量按《数据口径定义书》处理 |

## 主要结果

* **方向**：以接收为主，入向字节是出向的 3.64 倍（21.63 GB 对 5.95 GB），而两向包数近乎对称（0.93 倍）。
* **集中度**：高度头部化。主机级基尼系数 0.982，前 1% 主机承载 81.6% 的单向字节，仅前 100 台就占 59.9%；会话级基尼 0.97。
* **结构**：内网主机分四类（服务型 478、交互型 772、传输型 45、低频型 3,928），478 台服务型承载 72.2% 的内网字节；对外呈加密服务面（443 端口出向包数是入向的 5,317 倍）。
* **时间**：窗口内稳定：变异系数 0.163（第一段）与 0.186（第二段），主周期 21.3 秒与 40.1 秒，显著台阶仅 9.5% 与 10.2%，上尾有界（四个文件的形状参数均为负）。
* **异常线索**：共十条候选，没有一条同时满足"统计显著、做过误报评估、与同类主机可比对"，因此都只是线索而非确认异常。

## 数据

原始抓包**不分发**（36.2 GB，且是该单位自身的流量）。仓库里给的是出图所需的派生数据，因此不需要原始抓包
也能重建整套图表。

其中两张是主机级表（`data/probe_caliber/host_profile_v2_merged.csv`、`data/detect/cluster_points.csv`），
含有抓包中观察到的 IP 地址；另有少量汇总文件与 5 张图印出具体地址。保留原地址是为了让图表**逐字节复现**。
若需要不含地址的版本，运行 `python tools/anonymize_data.py`，它会把伪名化副本写到 `data_anonymized/`。
详见 `data/README.md`。

## 运行（出图）

出图流程自包含，只需要 `data/` 与 `figures/`：

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
bash figures/check_charts.sh        # 重新生成全部 24 张图到 figures/output/
```

`check_charts.sh` 会重出全部图，并检查三件事：无缺字告警、SVG 内无中日韩字符（在 Times New Roman 下会渲染成方框）、
每张 SVG 只声明 Times New Roman。

## 运行（分析）

`analysis/` 下的脚本读取原始抓包，并把派生数据写入 `data/`。它们需要不分发的 pcap；每个脚本头部都写明了
自己的输入与用法。保留这些脚本是为了让"从原始包到每个已发布数字"的路径可审计。

## 口径提醒

* **单向字节口径**；回环、非 IP 与跨接口重复按报告数据章节处理。
* **时间类结论只在两个连续观测段内成立**（192 秒 + 842 秒）。
* **每张图的图注都写明分母**（包数、字节、主机数还是会话数），因为分母不同答案就不同。
* 网段性质由**抽样**（DNS/SNI 名称）判定；`/24` 只是"外部单位"的近似，不等于一台主机，更不等于一个人。

## 工具与字体

Python 3.13 + numpy / pandas / matplotlib / scipy / scikit-learn / statsmodels（见 `requirements.txt`）。
图表统一使用 Times New Roman，输出 PNG（300 dpi）与保留真实文字的 SVG（可检索、非轮廓化）。
